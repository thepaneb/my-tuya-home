1. Nuvem Tuya (equivale ao wizard)

Pegue em platform.tuya.com → seu projeto → Overview. Região: use a mesma do Link App Account (BR = us).






2. Rede local (equivale ao scan.py)




PC e tomadas no mesmo Wi-Fi. Se voltar vazio, cheque firewall/rede guest.





2b. Histórico da nuvem


A nuvem guarda ~7 dias de relatórios (~18/h). Importa p/ o banco local de uma vez (~30 chamadas de API por tomada). Depois disso, minuto/dia/semana saem do banco local, sem gastar cota.









3. Tomadas (equivale a editar devices.json)


Preencha nome, id, key (da nuvem), ip (do scan), versão. Parent = id do pai em cascata (ex: desktop → setup).
